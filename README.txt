# Simulador de Torneos - README
Tomás Angel Rios

Esta aplicación fue creada como entrega final del curso "Python 3 - Nivel Incial" de UTN E-Learning
Se trata de un simulador de torneos de fútbol desarrollado en Python con la interfaz gráfica Tkinter y una base de datos SQLite. 
La aplicación permite gestionar un torneo entre 8 equipos y simular los resultados de los partidos.
Se incluye el script, una imagen png, la base de datos ya creada y el archivo "requirements.txt", que enumera todas las dependencias necesarias.

Uso de la aplicación
Agregar Equipo: Ingresa el nombre del equipo, la nacionalidad y el estadio, luego presiona el botón "Agregar Equipo" para agregar un equipo a la base de datos.
Borrar equipo: Selecciona un equipo de la lista y presiona el botón "Borrar equipo" para eliminarlo de la base de datos.
Borrar todos: Presiona el botón "Borrar todos" para eliminar todos los equipos de la base de datos.
Consultar participantes: Presiona el botón "Consultar participantes" para ver la lista de equipos en la base de datos.
Modificar equipo: Selecciona un equipo de la lista, actualiza los campos en la parte superior y presiona el botón "Modificar equipo" para actualizar la información del equipo.
Comenzar torneo: Presiona el botón "Comenzar torneo" para simular el torneo entre los equipos ingresados. El resultado se mostrará en la consola y en una ventana emergente.
Cambiar color: Presiona el botón "Cambiar color" para personalizar el color de fondo de la aplicación.

Notas adicionales
La aplicación utiliza una imagen llamada "torneo.png" como logotipo en la interfaz gráfica. Asegúrate de que esta imagen esté presente en la misma carpeta que el script.
La base de datos viene incluida, pero esta tambien se crea automáticamente en un archivo llamado "entrega_final.db" en la misma carpeta que el script.
